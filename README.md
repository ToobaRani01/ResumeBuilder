# AI Resume Analyzer

A modern Flask web application that analyzes PDF resumes using Google Gemini and presents results in a polished visual interface.

## Overview

This project extracts text from PDF resumes, sends it to Google Gemini via `langchain_google_genai`, and displays resume quality insights with:

- overall resume score
- gap checklist
- technical skill summary
- improvement recommendations

The frontend is designed for clean, user-friendly presentation and avoids raw JSON output.

## Key Features

- Upload and analyze PDF resumes
- Extract resume text using `PyPDF2`
- Generate ATS-style resume feedback with Gemini LLM
- Display score and analysis in a compact, modern UI
- Show progress while analysis is running
- Responsive layout for desktop and mobile

## Tech Stack

- Python 3.10+
- Flask
- Google Gemini via `langchain_google_genai`
- `langchain_core`
- `PyPDF2`
- `python-dotenv`
- HTML/CSS frontend

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/ResumeBuilder.git
cd ResumeBuilder
```

2. Create a virtual environment:

```bash
python -m venv .venv
```

3. Activate the environment:

```bash
.venv\Scripts\activate
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Create a `.env` file in the project root and add your Google API key:

```env
GOOGLE_API_KEY=your_google_api_key
```

## Usage

Start the app with:

```bash
python app.py
```

Then open the application in your browser:

```text
http://127.0.0.1:5000
```

Upload a resume PDF and view the analysis directly in the UI.

## Project Structure

- `app.py` — Flask application and Gemini integration
- `templates/index.html` — frontend UI with css and js 
- `requirements.txt` — Python dependencies

## Notes

- The app currently accepts only PDF resumes.
- The resume scoring and recommendations are generated by Gemini, so results depend on model output quality.
- If no text can be extracted from the PDF, the app returns a user-friendly error.
